cx 查到的发现、做过的修改放在看板的「收件箱」里，看过点「已读」；要你同意、选择或填写的也在这里，直接回答，cx 接着做。它需要 cx-board，两个插件都要安装。

你可以这样问：

- 把这几条改价建议放进收件箱，我晚点看。
- 收件箱里还有几条没回答？
- 把上周处理过的事整理成一份清单。

不打算回答的点「忽略」。处理过的都留在「已处理」里，不会删掉。

## 页面

- 卡片的顺序：cx 标了 `reply: true` 的最新一张，也就是它对你上一条消息的回答，排在最前；接着是要你回答的；再是告诉你的。每一部分里，按文件时间从新到旧。
- 一个标签里的卡片超过 32 张时，分几次读：看板说页面请求太频繁，页面等一秒再接着读。
- 标记卡片时，先读它的文件，再把标记写回去。在这次读和写之间写进这个文件的内容会丢失。
- 页面只改卡片 front matter 里的 `done`、`doneAt` 和 `answer`。写回时用 LF 换行和普通的 `---` 分隔线，不带 BOM。
