The to-do and question module of cx's board, installed beside `@comchatx/cx-board`.

With it, a file cx writes on the board can carry a kind: a finding or a change the seller reads, a proposal the seller agrees to, a choice or an input the seller answers. The seller dismisses what they will not answer, and sends every answer to cx at once, as one message, with Send to cx.

The package holds one skill, which tells cx what an entry's front matter holds and how the seller's answers come back. ComChatX draws the module's cards while both packages are installed.
